# kondre

Projectplan Kondre

Voor de verkiezingen van mei 2030 staat er een openbare website, Kondre, waarop iedereen kan zien wie er in De Nationale Assemblée zit, hoe vaak leden aanwezig zijn, hoe partijen in elkaar zitten, en waar een neutrale kieswijzer met stellingen voor 2030 draait. Extra functionaliteit volgt later.
